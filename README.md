# STC89C52-LCD1602-Clock
A simple digital clock implemented with STC89C52RC and LCD1602.
## Hardware

- STC89C52RC
- 11.0592 MHz Crystal
- LCD1602
## Features

- Display HH:MM:SS
- Display date
- LCD1602 driver implemented in C
- Software delay based on 11.0592 MHz clock

## Project Structure

src/
├── main.c
├── LCD1602.c
├── LCD1602.h
├── Delay.c
└── Delay.h

## MCU

STC89C52RC / 8051

Clock: 11.0592 MHz
